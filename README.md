# Systems Engineering & DSA Lab: Ground-Up Mastery

Welcome to the "Mechanical Sympathy" Lab. This project is dedicated to mastering Data Structures and Algorithms not as abstract mathematical concepts, but as physical entities that interact with CPU caches, memory controllers, and operating system primitives.

## 🧬 Philosophy: Ground-Level Exploration
In system software (compilers, kernels, EDA), $O(n)$ is only half the story. The other half is:
- **Spatial Locality:** Is the data in the L1 cache?
- **Predictability:** Can the branch predictor guess our next move?
- **Memory Density:** Are we wasting bytes on alignment padding?
- **Allocation Costs:** Are we fighting the kernel's `malloc` lock?

## 🛠 Lab Infrastructure
- **`include/harness.hpp`**: Our measurement tool. It uses ARM64 assembly (`cntvct_el0`) to read CPU cycles and `asm volatile` to prevent compiler optimizations from "cheating" during benchmarks.
- **`include/arena.hpp`**: A custom linear allocator for $O(1)$ memory management.
