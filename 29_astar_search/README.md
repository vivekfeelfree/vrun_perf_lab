# Module 29: A* Search

## 🎯 Goal
Demonstrate the efficiency of A* search on a 2D grid using a Manhattan distance heuristic.

## 🧠 Key Concept
A* is a graph traversal and path search algorithm that is often used in computer science due to its completeness, optimality, and optimal efficiency. It uses a heuristic function $h(n)$ to estimate the cost to reach the goal, significantly pruning the search space compared to Dijkstra's.

## 📊 Metrics to Watch
- **Visited Nodes:** Comparison of the number of nodes explored versus Dijkstra (breadth-first).
- **Path Length:** Verification of the shortest path.
