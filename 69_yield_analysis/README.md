# Module 69: Yield Analysis (Monte Carlo)

## 🎯 Goal
Estimate the percentage of chips that meet timing specifications under process variations using Monte Carlo simulation.

## 🧠 Key Concept
Process variations (e.g., fluctuations in transistor threshold voltage or wire thickness) lead to a statistical distribution of performance across manufactured chips. Monte Carlo simulation repeatedly samples these variations to estimate the **Yield**—the percentage of chips that function correctly within the target speed grade.

## 📊 Metrics to Watch
- **Yield Percentage:** Probability of meeting specification.
- **Statistical Confidence:** Convergence of the yield estimate as the number of trials increases.
