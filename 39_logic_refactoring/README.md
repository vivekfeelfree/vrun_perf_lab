# Module 39: Logic Refactoring

## 🎯 Goal
Demonstrate reducing literal count through algebraic factorization of boolean expressions.

## 🧠 Key Concept
Algebraic factoring (e.g., $ab + ac \rightarrow a(b+c)$) reduces the number of literals in a boolean expression, which directly correlates to a smaller area when mapped to a physical library.

## 📊 Metrics to Watch
- **Literal Count:** Total number of variable instances in the expression.
- **Factorization Efficiency:** Time taken to identify optimal divisors.
