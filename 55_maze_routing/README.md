# Module 55: Maze Routing

## 🎯 Goal
Implement a simple maze routing algorithm to find a path between two pins on a grid while avoiding obstacles.

## 🧠 Key Concept
Maze routing (often implemented using Lee's algorithm or BFS) finds the shortest path between two points on a grid by propagating a wave from the source until it reaches the target. This is a fundamental technique for both global and detailed routing in EDA.

## 📊 Metrics to Watch
- **Path Length:** Total number of grid cells in the final route.
- **Search Efficiency:** Number of grid cells visited during the search.
