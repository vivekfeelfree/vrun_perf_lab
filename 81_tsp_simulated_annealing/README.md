# Module 81: TSP (Simulated Annealing)

## 🎯 Goal
Use Simulated Annealing to find a near-optimal tour through a set of points, minimizing total Euclidean distance.

## 🧠 Key Concept
The Traveling Salesman Problem (TSP) is a classic NP-hard optimization problem. Simulated Annealing is a metaheuristic that allows for "hill-climbing" by accepting worse solutions with a certain probability, enabling the search to escape local minima and converge toward a global optimum for the tour length.

## 📊 Metrics to Watch
- **Total Distance:** Length of the finalized tour.
- **Annealing Schedule:** Effect of cooling rate on final result quality.
