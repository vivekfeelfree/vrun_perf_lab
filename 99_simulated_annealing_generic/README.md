# Module 99: Simulated Annealing (Generic)

## 🎯 Goal
Implement a reusable metaheuristic framework for solving complex combinatorial optimization problems.

## 🧠 Key Concept
This module demonstrates a generic C++ framework for Simulated Annealing. By abstracting the state representation, neighbor generation, and energy calculation, the same annealing engine can be used to solve diverse problems ranging from chip floorplanning to logistics and game AI.

## 📊 Metrics to Watch
- **Convergence Speed:** Time to reach a stable low-energy state.
- **Flexibility:** Ease of adapting the framework to new problem domains.
