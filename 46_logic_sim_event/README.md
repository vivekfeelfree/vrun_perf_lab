# Module 46: Event-Driven Simulation

## 🎯 Goal
Measure the efficiency of event-driven simulation where only affected gates are re-evaluated.

## 🧠 Key Concept
Event-driven simulation optimizes performance by only processing gates when their input signals change (events). This is particularly effective for large circuits with low switching activity.

## 📊 Metrics to Watch
- **Evaluations per Toggle:** Number of gates re-evaluated for a single primary input change.
- **Simulation Throughput:** Events processed per second.
