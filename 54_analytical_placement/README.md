# Module 54: Analytical Placement (Force-Directed)

## 🎯 Goal
Model nets as springs and use a force-directed heuristic to find node positions that minimize total wirelength.

## 🧠 Key Concept
Analytical placement formulations (like Force-Directed) treat the placement problem as a physical system. Attractive forces (Hooke's Law) pull connected nodes together, while spreading forces prevent overlap and ensure even density.

## 📊 Metrics to Watch
- **Wirelength Reduction:** Decrease in HPWL across iterations.
- **Convergence Rate:** Steps required to reach a stable placement.
