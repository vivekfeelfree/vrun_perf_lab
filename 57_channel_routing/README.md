# Module 57: Channel Routing

## 🎯 Goal
Assign horizontal segments (nets) to the minimum number of tracks within a routing channel using the Left-Edge Algorithm.

## 🧠 Key Concept
Channel routing is a restricted form of routing where all pins lie on the boundaries of a rectangular region. The Left-Edge Algorithm is a greedy approach that sorts segments by their left endpoint and packs them into the first available track.

## 📊 Metrics to Watch
- **Track Density:** Minimum number of tracks required to avoid overlaps.
- **Algorithm Efficiency:** Packing speed for large numbers of nets.
