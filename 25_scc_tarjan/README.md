# Module 25: Strongly Connected Components (Tarjan's)

## 🎯 Goal
Implement and measure Tarjan's algorithm for finding Strongly Connected Components (SCCs).

## 🧠 Key Concept
An SCC is a sub-graph where every node is reachable from every other node. Tarjan's algorithm uses a single DFS pass with discovery times and "low-link" values to identify SCCs in $O(V+E)$.

## 📊 Metrics to Watch
- **SCC Count:** Total number of SCCs identified.
- **Traversal Speed:** Linear time performance relative to graph size.
