# Module 76: Logical Effort Optimization

## 🎯 Goal
Use the Method of Logical Effort to determine the optimal number of stages and gate sizing for a multi-stage logic path.

## 🧠 Key Concept
Logical effort is a simple way to estimate the delay of a CMOS circuit. It helps designers choose the best topology (how many gates) and the best sizes for those gates to minimize the delay through a path that drives a specified capacitive load.

## 📊 Metrics to Watch
- **Path Delay:** Total delay in logical effort units.
- **Stage Scaling:** Relationship between total effort and the number of stages required.
