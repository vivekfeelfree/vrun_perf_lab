# Module 65: Metal Fill & Density Optimization

## 🎯 Goal
Add "dummy" metal fill to a layout to meet density requirements for Chemical Mechanical Polishing (CMP).

## 🧠 Key Concept
Modern fabrication uses CMP to flatten the wafer surface. If metal density is uneven across the chip, the "softer" areas will be polished more than the "harder" (denser) areas, leading to surface dishing. Metal fill (redundant metal squares) is added to low-density areas to ensure uniformity.

## 📊 Metrics to Watch
- **Fill Density:** Target density achieved (e.g., 35%).
- **Map Resolution:** Grid bin size used for analysis.
