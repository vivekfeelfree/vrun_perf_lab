# Module 96: K-Means Clustering

## 🎯 Goal
Implement the K-Means algorithm to partition a set of points into K clusters.

## 🧠 Key Concept
K-Means is a popular unsupervised learning algorithm for clustering data. It iteratively assigns points to the nearest cluster center (centroid) and then updates the centroids based on the mean of the assigned points. While the general clustering problem is NP-hard, K-Means usually converges quickly to a local optimum.

## 📊 Metrics to Watch
- **Centroid Stability:** Convergence of cluster centers across iterations.
- **Assignment Throughput:** Number of points processed per second.
