# Module 92: Subset Sum Problem (DP)

## 🎯 Goal
Determine if a subset of integers sums to a target value using an efficient dynamic programming approach.

## 🧠 Key Concept
Subset Sum is a classic decision problem in computer science. While it is NP-complete, it can be solved in pseudo-polynomial time using dynamic programming by maintaining a table of achievable sums for each prefix of the input set.

## 📊 Metrics to Watch
- **State Space:** Memory required for the boolean DP table.
- **Search Latency:** Time to fill the table and find the result.
