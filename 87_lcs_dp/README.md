# Module 87: Longest Common Subsequence (LCS)

## 🎯 Goal
Use dynamic programming to find the longest common subsequence between two strings.

## 🧠 Key Concept
The LCS problem identifies the longest sequence that appears in the same relative order in both input strings (though not necessarily contiguously). This is a fundamental string processing algorithm used for version control (diff), bioinformatics, and comparing netlist revisions.

## 📊 Metrics to Watch
- **Table Memory:** $O(NM)$ space required for the DP matrix.
- **Computation Time:** Quadratic growth with string lengths.
