# Module 26: Topological Sort & Critical Path

## 🎯 Goal
Model Static Timing Analysis (STA) by finding the critical path in a Directed Acyclic Graph (DAG).

## 🧠 Key Concept
The critical path is the longest path from any source to any sink in a DAG. In EDA, this represents the maximum delay through a circuit, which determines the maximum clock frequency.

## 📊 Metrics to Watch
- **Critical Path Delay:** The maximum cumulative delay.
- **Cycle Detection:** Verification that the graph is indeed a DAG.
