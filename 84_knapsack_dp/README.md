# Module 84: Knapsack Problem (DP)

## 🎯 Goal
Solve the 0/1 Knapsack problem using dynamic programming and measure time and memory scaling.

## 🧠 Key Concept
The 0/1 Knapsack problem involves choosing a subset of items with given weights and values to maximize total value without exceeding a capacity limit. The dynamic programming approach solves this in $O(NW)$ time and space by breaking it down into sub-problems based on item count and remaining capacity.

## 📊 Metrics to Watch
- **Table Size:** Memory consumption of the DP matrix.
- **Computation Time:** $O(NW)$ growth with respect to items and capacity.
