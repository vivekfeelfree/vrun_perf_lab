# Module 36: Boolean Rewriting

## 🎯 Goal
Demonstrate local sub-graph rewriting to reduce AIG (And-Inverter Graph) node count.

## 🧠 Key Concept
Boolean Rewriting replaces small, sub-optimal logic structures with pre-computed optimal ones. Combined with Structural Hashing (Strashing), it is a powerful technique for technology-independent optimization.

## 📊 Metrics to Watch
- **Node Count:** Reduction in total AIG nodes.
- **Optimization Speed:** Efficiency of pattern matching.
